## Sprint 001 selection — 19 minutes 45 seconds

All videos below are by Piyush Garg. Use the selected portions, then apply them to an actual repository. Familiar sections may be skipped after explaining the workflow; the whole bootcamp is not assigned.

| Resource | Exact selected portion | Purpose |
| --- | --- | --- |
| [How to Find the Best Repositories for Open Source Contribution](https://www.youtube.com/watch?v=noKgvN_42Hk&t=35s) | **00:35–03:00** (2:25) | Begin with software you understand/use and a compatible stack; stop before the course promotion. Repository health still needs the checks in our method. |
| [Open Source Crash Course — Beginner Guide to Open Source](https://www.youtube.com/watch?v=o6xikISiz2w&t=520s) | **08:40–20:15** (11:35) | Understand and verify an issue, inspect existing work, then orient around forks and task branches. |
| [Same crash course, later section](https://www.youtube.com/watch?v=o6xikISiz2w&t=1470s) | **24:30–30:15** (5:45) | Validation reminder, commit/push, PR description and issue linking, review, and starting subsequent work. |

Skip the intervening icon-edit demonstration and the event/bounty material outside these bounds. Examples demonstrate mechanics; they do not select a repository or justify cosmetic contribution farming. Create the branch before editing, inspect what you stage, and follow the target project's rules rather than copying every demonstration shortcut.

**One optional lookup:** GitHub's [Contributing to a project](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project), only the section corresponding to a blocked action: forking, cloning, branch creation, pushing, or opening a PR. No end-to-end reread or public tutorial PR is assigned. The chosen repository's own README/CONTRIBUTING and test instructions are working documents, not an extra course.
